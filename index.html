Dashboard settings

Your calendar is private by default. You can import an .ics export to display appointments locally, without uploading them to any service. Imports are snapshots, not automatic sync.

Events are processed on this device and saved in this browser. For iCloud on a Mac: Calendar → File → Export → Export. You can also use a downloaded .ics calendar file.
Optional: automatic iCloud sync

To refresh iCloud automatically, deploy the included protected Cloudflare Worker bridge, then enter its URL and access token below. This is optional and requires making a calendar readable via a secret public link in iCloud. See README.md for privacy details.

Do not paste your Apple ID password here. The token is stored only in this browser, but anyone with physical access to this iPad may be able to retrieve it.

Add an appointment directly on this iPad. Manually added events remain separate from any imported iCloud events.

Aarhus is the default. You can change the place name and coordinates if you want weather closer to your home.

For example, you can use coordinates copied from a map. Weather updates every 15 minutes when the dashboard is open.
